# Partner logo assets

The SVG files in this folder are clean, image-based placeholders for the partner names shown in the homepage marquee. The homepage first tries to load an official PNG and falls back to these SVG placeholders when one is not available.

Drop the approved official PNG logo files into this folder using these filenames so the homepage needs no code changes:

- `sars.png`
- `cipc.png`
- `sait.png`
- `saipa.png`
- `saica.png`

Official logo files should be supplied with permission for website use. Transparent files work best, with the logo artwork sized to fit a roughly 144px by 36px area.
