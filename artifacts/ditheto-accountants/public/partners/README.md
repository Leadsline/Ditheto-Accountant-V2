# Partner logo assets

The homepage marquee uses approved logo images for UIF, CIPC, CSD, SAIPA, COIDA, CIDB, SARS, SAIT, and SAICA. UIF, CSD, SAIPA, COIDA, and CIDB use the files supplied for the site; retain their filenames and replace only with approved updated assets.

Keep these filenames so the homepage needs no code changes:

- `sars.png`
- `uif.jpg`
- `cipc.png`
- `csd.png`
- `sait.png`
- `saipa.png`
- `coida.jpg`
- `cidb.jpg`
- `saica.png`

Logo files should be supplied with permission for website use. Transparent files work best, with the logo artwork sized to fit a roughly 144px by 36px area.
